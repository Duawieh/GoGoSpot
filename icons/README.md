# 图标

所有图标都在这个目录里。注意：**程序运行时不读这里的文件** —— exe 的图标是编译时
嵌进资源的，悬浮清单和托盘图标是运行时用 GDI+ 现画的（比例和这里的 PNG 一致）。

```
icons/
├─ app/         圆角方块底，对外的门面：exe 图标、控制台 favicon
├─ dark/        透明底，深色主题用（#5676ff → #b476ff）
├─ light/       透明底，浅色主题用（#4f6bff → #8b5cf6）
├─ app.ico      给 exe 用的图标，由 app/ 里的 PNG 打包
└─ preview.png  三套的总览
```

三套都是 11 档：16 / 24 / 32 / 48 / 64 / 96 / 128 / 180 / 256 / 512 / 1024。

## 几个约定

- **16 和 24 两档是单独加粗的**（线宽按 94/1024，不是 58/1024）。直接从 256 缩下去
  会糊成灰雾，细线撑不住。
- `app.ico` 由 `.workbuddy-ai/tools/make_ico.py` 从 `app/*.png` 重新打包，
  七档尺寸各自用自己那张图，不走自动缩放。
- `web/icon.png` 是控制台的 favicon，构建时从 `app/icon-64.png` 复制过去。
  服务端只托管 `web/` 目录，浏览器访问不到 `icons/`。
- 换图标之后如果资源管理器还显示旧的，是图标缓存没刷新。

## 改动流程

改图标时，先替换三套 PNG，用任意工具把它们打包成 `app.ico`，再按 README 重新编译。
悬浮清单和托盘里的标识不读这些 PNG，而是画在 `src/widget.cpp` 的 `drawMark()` 里，
比例要跟着一起改。
